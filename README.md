# 落幕曲枪战比赛

Minecraft 1.20.1 Forge 整合包「落幕曲」1.6.6.1 的玩家对战比赛资料。远程仓库：https://github.com/liuliubiu/minecraft-pubg

## 仓库里有什么

| 路径 | 用途 |
| --- | --- |
| `枪战比赛数据包/` | 弹药箱、武器箱、装备箱、物资箱。安装和指令见 `枪战比赛数据包/使用说明.txt` |
| `落幕曲参考/` | 给后续修改用的包体文本：模组文件名、KubeJS 脚本、默认枪械数据、绿葡萄刀和手雷定义、文本配置 |
| `落幕曲参考/包体说明.txt` | 关键模组版本和物品 NBT 键 |

完整懒人包约 4.6GB，含超过 GitHub 单文件 100MB 限制的压缩包和模组，没有放进仓库。本地仍在 `落幕曲懒人包/`，该目录被 `.gitignore` 排除。

枪械物品是 `tacz:modern_kinetic_gun`，NBT 键 `GunId`。子弹是 `tacz:ammo`，键 `AmmoId`。近战是 `lrtactical:melee`，键 `MeleeWeaponId`。投掷物是 `lrtactical:throwable`，键 `ThrowableId`。

## 现在就能接着做的事

换一台设备克隆本仓库后，可以直接改箱子概率、增删枪械条目、写原版数据包函数。开局全服提示可以用 `/title` 和 `/tellraw`，不需要再上传模组。计分板的目标、显示和世界边界指令也可以先写成数据包。

`落幕曲参考/mods-list.txt` 能确认服务端装了哪些模组。`config/skyarena-common.toml` 是刷怪祭坛，不是玩家对战模式。

## 地图、计分、击杀榜还缺的信息

这些功能还不能只靠当前仓库做完：

- **地图**：仓库里没有存档。建筑、出生点、箱子坐标都在面板服的世界里。要改地图，需要把坐标或区域写进本文件，或另外提供可下载的世界。不要把含玩家数据的完整存档直接提交。
- **击杀榜**：永恒枪械的子弹不一定会计入原版「玩家击杀数」。写成 KubeJS 的死亡监听之后，必须在服务器上用枪打一枪验证凶手是不是玩家。当前仓库没有 `tacz` 本体 jar，无法从源码确认击杀归属。
- **开局提示**：提示文案和触发方式（管理员手动执行，或玩家到齐后自动开始）还没有写下来。
- **面板服运行参数**：`server.properties`、游戏规则、世界文件夹实际名字没有入库。KubeJS 目录和 `world` 同级，不在存档里面。

补上这些信息后再改对应功能，并同步更新本文件。
